Support

ArmAware is developed by Joshua Clarke Development.

To report a problem or suggest an improvement, open an issue on GitHub, or use the support contact on the Microsoft Store listing.

What to include

  • ArmAware version, Windows version and device.
  • The affected application's name and version.
  • What you expected, what happened and how to reproduce it.
  • The evidence and any warning text ArmAware showed, with private paths redacted.

Please do not upload your complete application inventory. Check screenshots and diagnostics for personal information and file paths before sharing them publicly.

Unknown or inferred results

Unknown means the evidence was not strong enough to decide. When several program files agree, ArmAware may show an inferred result with medium confidence. Results describe the inspected files; they do not prove that every dependency or process is native.

Security issues

Please report security problems privately through GitHub private vulnerability reporting rather than a public issue.

Online check problems

A catalog failure leaves the rest of the scan available. Check that App Installer (Windows Package Manager) is installed and up to date, and that your network and source settings allow access. ArmAware never accepts source agreements for you; run winget list once in a terminal to review them.

Switching an application

Close the application and back up settings and important data first. Review the exact package, version and scope. Uninstalling can remove data. If removal fails, the combined script stops before installing. If the ARM64 installation fails after removal, reinstall the original application from its trusted installer before trying again.

The publisher does not receive scan data. See the privacy policy for details.
