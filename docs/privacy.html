Privacy policy

Effective 31 October 2026. Publisher: Joshua Clarke Development.

  • No account, analytics, advertising or telemetry.
  • Scans run on your PC. No inventory report is uploaded.
  • Online checks are optional and go through Windows Package Manager to Microsoft's catalogs.
  • Apps are only installed or removed when you confirm a command.

Local inspection

ArmAware inspects installed application metadata and program files on your Windows PC. It reads uninstall registry entries, current-user package information and executable architecture metadata. It takes a one-off snapshot of running program paths to help identify an application's main executable; it does not continuously monitor processes. It does not read the contents of your personal documents.

ArmAware has no account system, analytics, advertising or telemetry backend. It does not upload an inventory report. Local scanning does not require online package checks.

Optional external services

When online checks are enabled, Windows Package Manager connects to Microsoft's community Winget and Microsoft Store catalogs. Catalog requests can include package identifiers, versions, package family names, product codes and market information, together with normal network information such as your IP address. Those services operate under their own privacy policies and source agreements. ArmAware does not accept source agreements on your behalf.

Opening a manifest link sends a normal browser request to GitHub. The "Search for an ARM64 build" action opens Bing with the application's name as the search query. The App Installer link opens Microsoft Store. The separate command-line manifest diagnostic can also request metadata from GitHub.

Settings, cache and diagnostics

Preferences, catalog metadata and startup error details are stored locally in an ArmAware folder in your Windows local app data. The Winget catalog cache expires after seven days. Startup diagnostics can contain file paths and error details; they are never sent to the publisher automatically. Windows can redirect local app data for packaged applications.

Exports and support

Reports are saved only when you export them or redirect command-line output. JSON and CSV reports can include application names, versions, publishers, installation paths and package identifiers. Review and redact them before sharing. Files you save outside the application's data folder can remain after uninstalling.

If you open a public support issue or send diagnostics, the information you provide is shared with that service and its participants. Do not include passwords, keys, private inventories or unredacted personal paths.

Commands that change applications

ArmAware can display or copy installation, removal and update commands. Running a command requires your confirmation and starts a visible terminal. Windows Package Manager and the selected installer may download software, contact their services and change files or settings under their own terms. Back up important data before switching an application.

Your choices

You can keep online checks disabled, choose what to export and decline terminal commands. Local preferences and cache can be removed from the app's local data folder while the application is closed. Deleting exported reports, or information you shared with third-party services, is up to you.

Questions and changes

Use the support page for questions. This page will be updated if ArmAware's data handling changes, with a new effective date.
